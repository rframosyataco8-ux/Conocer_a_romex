# Exportadora Romex S.A. — Interfaz Educativa

Proyecto desarrollado para la **Alianza SENATI**.

Interfaz web profesional e interactiva que presenta:

- **Conoce Nosotros** → Enlace directo al sitio oficial de Romex
- **Línea de Tiempo** → Hitos históricos de la empresa (1957 – 2024)
- **Transformación del Grano** → Proceso industrial del cacao desde la recepción hasta el despacho

## Cómo ver el proyecto

Abre el archivo `index.html` en cualquier navegador, o visita:

**https://rframosyataco8-ux.github.io/romex-senati-cacao/**

(si activas GitHub Pages)

## Tecnologías

- HTML5 + CSS3 moderno (variables CSS, Flexbox/Grid)
- JavaScript vanilla
- Google Fonts (Inter) + Material Icons
- Imágenes de Wikimedia Commons y Unsplash

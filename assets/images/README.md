# Carpeta de Imágenes

Coloca aquí las imágenes que se usarán en el módulo **Transformación del Grano**.

## Nombres de archivos requeridos

| Archivo                  | Descripción                    |
|--------------------------|--------------------------------|
| `01-recepcion.jpg`       | Recepción de materia prima     |
| `02-seleccion.jpg`       | Selección y limpieza           |
| `03-secado.jpg`          | Secado y control de humedad    |
| `04-tostado.jpg`         | Tostado                        |
| `05-nibs.jpg`            | Descascarillado / Nibs         |
| `06-calidad.jpg`         | Control de calidad             |
| `07-almacen.jpg`         | Almacenado y despacho          |

## Recomendaciones

- Formato preferido: **JPG** o **PNG**
- Tamaño recomendado: **800px – 1200px** de ancho
- Peso: idealmente menos de **300 KB** por imagen (para carga rápida)
- Puedes usar `.jpg`, `.jpeg`, `.png` o `.webp` (solo cambia la extensión en `js/data.js` si usas otra)

## Cómo agregar tus imágenes

1. Descarga o toma las fotos del proceso.
2. Renómbralas exactamente como se indica arriba.
3. Cópialas dentro de esta carpeta (`assets/images/`).
4. Abre el proyecto y verifica que se vean correctamente.

> Si una imagen no carga, se ocultará automáticamente para no romper el diseño.
